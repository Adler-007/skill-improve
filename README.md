# 个人知识系统

一个基于 Vite + Vue + TypeScript 的个人知识汇总展示网站，用于展示系统理解能力、前端工程、AI 工具使用、项目复盘和个人方法论沉淀。

## 技术栈

- Vite
- Vue 3
- TypeScript
- Vue Router

## 本地启动

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

默认访问地址：

```text
http://127.0.0.1:5173
```

## 构建

```bash
npm run build
```

构建产物会生成在 `dist/` 目录。
